## Условие

Прямоугольный треугольник с катетами $c = 2\text{ см}$ и $h = 4\text{ см}$ расположен перед собирающей линзой с фокусным расстоянием $F = 10\text{ см}$, как показано на рисунке. Постройте изображение треугольника, даваемое линзой. Чему равна площадь этого изображения? Ответ выразите в квадратных сантиметрах ($\text{см}^2$).

## Рисунок (TikZ)

```latex
\begin{tikzpicture}[scale=0.9, every node/.style={font=\footnotesize}]
    \draw[xstep=1, ystep=1, gray!30, thin] (-4,-2) grid (3,2);
    
    \draw[thick, black] (-4,0) -- (3,0);
    \draw[ultra thick, black, <->] (0,-1.8) -- (0,1.8);
    
    \draw[thick, black] (-1,0.1) -- (-1,-0.1) node[below] {$F$};
    \draw[thick, black] (-2,0.1) -- (-2,-0.1) node[below] {$2F$};
    \draw[thick, black] (1,0.1) -- (1,-0.1) node[below] {$F$};
    
    % Треугольник (катеты c и h)
    \draw[thick, black, fill=gray!50] (-2,0) -- (-2,1.2) -- (-1.4,0) -- cycle;
    \node[left] at (-2,0.6) {$h$};
    \node[below] at (-1.7,0) {$c$};
    
\end{tikzpicture}
```

## Решение

По рисунку вертикальный катет $h$ лежит в плоскости, проходящей через двойной фокус: $d_1 = 2F = 20\,\text{см}$; катет $c$ лежит на главной оптической оси и направлен к линзе, так что вершина острого угла на оси находится на расстоянии $d_2 = 2F - c = 18\,\text{см}$.

Построение: изображение вершины катета $h$ строим двумя лучами — параллельным оси (после линзы проходит через фокус) и через оптический центр (не преломляется). Изображение отрезка прямой в тонкой линзе — отрезок прямой, поэтому изображение треугольника — прямоугольный треугольник с катетами $h'$ (перпендикулярен оси) и $c'$ (на оси).

По формуле тонкой линзы $\dfrac{1}{d} + \dfrac{1}{f} = \dfrac{1}{F}$, $f = \dfrac{dF}{d - F}$:
$f_1 = \dfrac{20\cdot 10}{20 - 10}\,\text{см} = 20\,\text{см}$, $f_2 = \dfrac{18\cdot 10}{18 - 10}\,\text{см} = 22{,}5\,\text{см}$.

Увеличение для катета $h$: $\Gamma = \dfrac{f_1}{d_1} = 1$, поэтому $h' = h = 4\,\text{см}$ (изображение перевёрнутое). Катет $c' = f_2 - f_1 = 2{,}5\,\text{см}$.

Площадь изображения $S' = \dfrac{1}{2}h'c' = \dfrac{1}{2}\cdot 4\cdot 2{,}5\,\text{см}^2 = 5\,\text{см}^2$.
