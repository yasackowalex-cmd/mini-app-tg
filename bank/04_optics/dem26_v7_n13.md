## Условие

Какая из точек (1, 2, 3, 4, 5 или 6), показанных на рисунке, является изображением точечного источника света $S$, полученным в тонкой собирающей линзе с фокусным расстоянием $F$?

## Рисунок (TikZ)

```latex
\begin{tikzpicture}[scale=0.85, every node/.style={font=\small}]
\draw[thick] (-4.2,0) -- (4.2,0);
  \draw[very thick, {Stealth[scale=0.9]}-{Stealth[scale=0.9]}] (0,-1.6) -- (0,1.6);
  \foreach \x/\l in {-3/2F, -1.5/F, 1.5/F, 3/2F} { \draw[thick] (\x,0.08) -- (\x,-0.08); \node[below, font=\footnotesize] at (\x,-0.05) {$\l$}; }
  \node at (3,0.9) {$\sun$}; \node[above=3pt, font=\footnotesize] at (3,0.9) {$S$};
  \fill (3.4,-0.6) circle (1.5pt) node[right, font=\footnotesize] {1};
  \fill (-0.9,-0.3) circle (1.5pt) node[right, font=\footnotesize] {2};
  \fill (-2.0,0.8) circle (1.5pt) node[right, font=\footnotesize] {3};
  \fill (-3.3,1.4) circle (1.5pt) node[left, font=\footnotesize] {4};
  \fill (-2.0,-0.6) circle (1.5pt) node[right, font=\footnotesize] {5};
  \fill (-3,-0.9) circle (1.5pt) node[left, font=\footnotesize] {6};
\end{tikzpicture}
```

## Решение

Источник находится на двойном фокусном расстоянии: $d = 2F$. По формуле тонкой линзы $\dfrac1d + \dfrac1f = \dfrac1F$ получаем $f = 2F$, увеличение $\Gamma = \dfrac fd = 1$.

Изображение действительное, перевёрнутое, того же размера, по другую сторону линзы на расстоянии $2F$, на той же высоте под осью. Построение: луч, параллельный оси, после линзы проходит через фокус; луч через оптический центр не преломляется.

```latex
\begin{tikzpicture}[scale=0.85, every node/.style={font=\small}]
\draw[thick] (-4.2,0) -- (4.2,0);
  \draw[very thick, {Stealth[scale=0.9]}-{Stealth[scale=0.9]}] (0,-1.6) -- (0,1.6);
  \foreach \x/\l in {-3/2F, -1.5/F, 1.5/F, 3/2F} { \draw[thick] (\x,0.08) -- (\x,-0.08); \node[below, font=\footnotesize] at (\x,-0.05) {$\l$}; }
  \node at (3,0.9) {$\sun$}; \node[above=3pt, font=\footnotesize] at (3,0.9) {$S$};
  \draw[brandPrimary, thick] (3,0.9) -- (0,0.9) -- (-3,-0.9);
  \draw[brandPrimary, thick] (3,0.9) -- (-3,-0.9);
  \fill (-3,-0.9) circle (1.6pt) node[left, font=\footnotesize] {$S'$};
\end{tikzpicture}
```

Ответ: точка 6.
