## Условие

Электрическая цепь состоит из источника тока и реостата. Внутреннее сопротивление источника $r = 2$~Ом. Сопротивление реостата можно изменять непрерывно в пределах от $1$ до $5$~Ом. Максимальная тепловая мощность тока $P_\text{max}$, выделяемая на реостате, равна $4{,}5$~Вт. Какая тепловая мощность будет выделяться на реостате при его максимальном сопротивлении?

## Решение

1. По закону Ома для полной цепи $\mathcal{E} = I(R + r)$, напряжение на реостате $U = IR = \mathcal{E} - Ir$, где $\mathcal{E}$ — ЭДС источника, $I$ — сила тока, $R$ — сопротивление реостата.

2. Мощность на реостате
$$P = UI = \mathcal{E}I - I^2r.$$
Зависимость $P(I)$ — парабола с ветвями вниз, она обращается в нуль при $I = 0$ и $I = \dfrac{\mathcal{E}}{r}$. Максимум — посередине, при $I = \dfrac{\mathcal{E}}{2r}$, то есть при $R = r = 2$~Ом. Это значение входит в пределы изменения сопротивления реостата.

3. Максимальная мощность
$$P_\text{max} = \frac{\mathcal{E}}{2r}\cdot\mathcal{E} - \frac{\mathcal{E}^2}{4r^2}\cdot r = \frac{\mathcal{E}^2}{4r},\qquad \mathcal{E} = 2\sqrt{rP_\text{max}} = 2\sqrt{2\cdot 4{,}5} = 6~\text{В}.$$

4. При максимальном сопротивлении $R_\text{max} = 5$~Ом:
$$P = I^2R_\text{max} = \frac{\mathcal{E}^2R_\text{max}}{(R_\text{max} + r)^2} = \frac{6^2\cdot 5}{(5 + 2)^2} = \frac{180}{49} \approx 3{,}7~\text{Вт}.$$
