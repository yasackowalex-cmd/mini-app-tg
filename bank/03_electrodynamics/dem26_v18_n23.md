## Условие

Альфа-частица с кинетической энергией $W = 10^{-14}$~Дж движется по окружности перпендикулярно линиям магнитной индукции однородного магнитного поля с индукцией $B = 0{,}5$~Тл. Определите радиус этой окружности. Релятивистскими эффектами пренебречь.

## Решение

1. На альфа-частицу действует сила Лоренца $F_\text{Л} = qvB$, она перпендикулярна скорости и сообщает частице центростремительное ускорение (см. рисунок, поле направлено от нас).

```latex
\begin{tikzpicture}[scale=1.0, every node/.style={font=\small}]
\foreach \x in {-1.6,-0.8,0,0.8,1.6} { \foreach \y in {-1.6,-0.8,0,0.8,1.6} { \node[gray] at (\x,\y) {$\times$}; } }
  \draw[thick, dashed, brandPrimary] (0,0) circle (1.2);
  \fill (0,-1.2) circle (2pt);
  \draw[-{Stealth[scale=0.9]}, very thick] (0,-1.2) -- (1.1,-1.2) node[below] {$\vec v$};
  \draw[Fvec] (0,-1.2) -- (0,-0.2) node[left] {$\vec F_\text{Л}$};
  \fill (0,0) circle (1pt); \draw[<->] (0.05,0.05) -- (0.83,0.83); \node at (0.3,0.62) {$R$};
  \node at (1.9,1.95) {$\vec B$};
\end{tikzpicture}
```

По второму закону Ньютона
$$\frac{mv^2}{R} = qvB \;\Rightarrow\; R = \frac{mv}{qB}.$$

2. Кинетическая энергия $W = \dfrac{mv^2}{2}$, отсюда $mv = \sqrt{2mW}$ и
$$R = \frac{\sqrt{2mW}}{qB}.$$

3. Масса альфа-частицы $m = 4\cdot 1{,}66\cdot 10^{-27}$~кг, заряд $q = 2e = 3{,}2\cdot 10^{-19}$~Кл:
$$R = \frac{\sqrt{2\cdot 6{,}64\cdot 10^{-27}\cdot 10^{-14}}}{3{,}2\cdot 10^{-19}\cdot 0{,}5} \approx 0{,}072~\text{м} = 7{,}2~\text{см}.$$

Ответ: $R \approx 7{,}2$~см.
