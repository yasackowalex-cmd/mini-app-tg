## Условие

Конденсатор $C_1$ заряжен до напряжения $U = 300\text{ В}$ и включён в последовательную цепь из резистора $R = 300\text{ Ом}$, незаряженного конденсатора $C_2 = 2\text{ мкФ}$ и разомкнутого ключа $K$ (см. рисунок). После замыкания ключа в процессе перезарядки конденсаторов в цепи выделяется количество теплоты $Q = 30\text{ мДж}$. Чему равна ёмкость конденсатора $C_1$? Ответ выразите в микрофарадах (мкФ).

## Рисунок (TikZ)

```latex
\begin{circuitikz}[european, scale=1, every node/.style={font=\footnotesize}]
  \draw (0,0) to[C, l=$C_1$] (0,2) -- (0.9,2)
        to[nos, l=$K$] (2.1,2) -- (3,2)
        to[C, l_=$C_2$] (3,0)
        to[R, l_=$R$] (0,0);
\end{circuitikz}
```

## Решение

Начальный заряд первого конденсатора $q = C_1U$. После замыкания ключа ток течёт, пока напряжения на конденсаторах не сравняются; в конечном состоянии ток равен нулю, напряжение на резисторе тоже, и конденсаторы имеют одинаковое напряжение $U'$ (обозначим так).

По закону сохранения электрического заряда $C_1U = (C_1 + C_2)U'$, откуда $U' = \dfrac{C_1U}{C_1 + C_2}$.

По закону сохранения энергии выделившаяся теплота равна убыли энергии электрического поля конденсаторов ($W = \dfrac{CU^2}{2}$):
$Q = \dfrac{C_1U^2}{2} - \dfrac{(C_1 + C_2)U'^2}{2} = \dfrac{C_1U^2}{2} - \dfrac{C_1^2U^2}{2(C_1 + C_2)} = \dfrac{C_1C_2U^2}{2(C_1 + C_2)}$.

Отсюда $\dfrac{1}{C_1} + \dfrac{1}{C_2} = \dfrac{U^2}{2Q}$, $C_1 = \dfrac{2QC_2}{C_2U^2 - 2Q}$.

$C_1 = \dfrac{2\cdot 30\cdot 10^{-3}\cdot 2\cdot 10^{-6}}{2\cdot 10^{-6}\cdot 300^2 - 2\cdot 30\cdot 10^{-3}}\,\text{Ф} = \dfrac{1{,}2\cdot 10^{-7}}{0{,}12}\,\text{Ф} = 1\cdot 10^{-6}\,\text{Ф} = 1\,\text{мкФ}$.
