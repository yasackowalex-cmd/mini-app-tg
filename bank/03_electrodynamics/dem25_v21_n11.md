## Условие

Восемь одинаковых резисторов с сопротивлением $r = 1$~Ом соединены в электрическую цепь, по которой течёт ток $I = 8$~А (см. рисунок). Какое напряжение показывает вольтметр? Вольтметр считать идеальным.

## Решение

Вольтметр идеальный, ток через него не идёт. Он подключён между узлом сразу после первого резистора и точкой между двумя нижними резисторами.

Две нижние ветви (по $2r$ каждая) соединены параллельно: $\dfrac{2r}{2} = r$. Вместе с резистором перед ними средняя ветвь имеет сопротивление $r + r = 2r$, верхняя ветвь — тоже $2r$. Ветви одинаковые, ток $8$~А делится поровну: по $4$~А.

В средней ветви ток $4$~А идёт через первый резистор, затем делится поровну между нижними ветвями: по $2$~А. Вольтметр показывает напряжение на первом резисторе средней ветви и первом резисторе нижней ветви:
$$U = 4\cdot 1 + 2\cdot 1 = 6~\text{В}.$$
