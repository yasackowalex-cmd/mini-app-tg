## Условие

Положительно заряженная частица массой $m = 1{,}6\cdot 10^{-25}$~кг и зарядом $q = 4{,}8\cdot 10^{-19}$~Кл движется по окружности перпендикулярно линиям индукции однородного магнитного поля с угловой скоростью $\omega = 6\cdot 10^{6}$~рад/с. Определите модуль индукции магнитного поля. Релятивистскими эффектами пренебречь.

## Решение

1. На частицу действует сила Лоренца $F_\text{Л} = qvB$ (скорость перпендикулярна $\vec B$), она сообщает частице центростремительное ускорение $a = \omega^2R$. По второму закону Ньютона
$$qvB = m\omega^2R.$$

2. Скорость при движении по окружности $v = \omega R$, тогда $q\omega RB = m\omega^2R$, откуда
$$B = \frac{m\omega}{q} = \frac{1{,}6\cdot 10^{-25}\cdot 6\cdot 10^6}{4{,}8\cdot 10^{-19}} = 2~\text{Тл}.$$

Ответ: $B = 2$~Тл.
