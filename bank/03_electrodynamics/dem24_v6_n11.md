## Условие

По проводнику течёт постоянный электрический ток. Заряд, прошедший по проводнику, растёт с течением времени согласно представленному графику (см. рисунок). За какое время по проводнику протечёт заряд $45$~Кл?

## Решение

По графику за $4$~с прошёл заряд $12$~Кл, сила тока $I = \dfrac{12}{4} = 3$~А. Ток постоянный, поэтому заряд $q = 45$~Кл протечёт за
$$t = \frac{q}{I} = \frac{45}{3} = 15~\text{с}.$$
