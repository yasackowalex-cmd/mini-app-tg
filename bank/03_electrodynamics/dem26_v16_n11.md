## Условие

По проводнику течёт постоянный электрический ток. Заряд, прошедший через поперечное сечение проводника, растёт с течением времени согласно представленному графику (см. рисунок). Определите силу тока в проводнике.

[[рис 1]]

## Рисунок (TikZ)

```latex
\begin{tikzpicture}[scale=1.1, every node/.style={font=\small}]
\draw[step=0.5, gray!35, thin] (0,0) grid (2,2);
  \draw[-{Stealth[scale=0.8]}, thick] (0,0) -- (2.5,0) node[below right] {$t$, с};
  \draw[-{Stealth[scale=0.8]}, thick] (0,0) -- (0,2.4) node[left] {$q$, Кл};
  \foreach \i in {1,2,3,4} { \node[below] at (0.5*\i,0) {\i}; }
  \foreach \i in {1,2,3} { \node[left] at (0,0.5*\i) {\i}; }
  \node[below left] at (0,0) {$0$};
  \draw[very thick, brandPrimary] (0,0) -- (1.75,1.75);
\end{tikzpicture}
```

## Решение

Сила тока $I = \dfrac{q}{t}$. По графику за $3$~с прошёл заряд $3$~Кл:
$$I = \frac{3}{3} = 1~\text{А}.$$
