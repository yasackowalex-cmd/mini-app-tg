## Условие

Квадратная проволочная рамка со стороной $l = 10$~см находится в однородном магнитном поле с индукцией $\vec B$. На рисунке изображена зависимость проекции вектора $\vec B$ на перпендикуляр к плоскости рамки от времени. Какое количество теплоты выделится в рамке за время $t = 10$~с, если сопротивление рамки $R = 0{,}2$~Ом?

## Решение

1. Магнитный поток через рамку $\Phi = B_nS$, где $S = l^2$. По закону электромагнитной индукции Фарадея в рамке возникает ЭДС
$$\mathcal{E} = -\frac{\Delta\Phi}{\Delta t} = -\frac{\Delta B_n}{\Delta t}l^2.$$

2. Сила тока по закону Ома $I = \dfrac{\mathcal{E}}{R}$, количество теплоты по закону Джоуля — Ленца
$$Q = I^2R\Delta t = \frac{l^4}{R}\cdot\frac{(\Delta B_n)^2}{\Delta t}.$$

3. По графику на первом участке $\Delta t_1 = 4$~с, $\Delta B_1 = -0{,}4 - 0{,}6 = -1$~Тл; на втором $\Delta t_2 = 6$~с, $\Delta B_2 = 0{,}2 - (-0{,}4) = 0{,}6$~Тл. Суммарная теплота
$$Q = \frac{l^4}{R}\left(\frac{(\Delta B_1)^2}{\Delta t_1} + \frac{(\Delta B_2)^2}{\Delta t_2}\right) = \frac{0{,}1^4}{0{,}2}\left(\frac{1^2}{4} + \frac{0{,}6^2}{6}\right) = 1{,}55 \cdot 10^{-4}~\text{Дж} = 155~\text{мкДж}.$$
