## Условие

По горизонтальным шероховатым рельсам с пренебрежимо малым электрическим сопротивлением могут скользить два одинаковых стержня сопротивлением $R = 0{,}1$~Ом каждый. Расстояние между рельсами $l = 10$~см. Рельсы со стержнями находятся в однородном вертикальном магнитном поле с индукцией $B = 1$~Тл (см. рисунок).

[[рис 1]]

Если на первый стержень действует горизонтальная сила величиной $F = 0{,}1$~Н, направленная вдоль рельсов, то оба стержня движутся поступательно равномерно с разными скоростями. Какова скорость движения первого стержня относительно второго? Самоиндукцией контура пренебречь.

## Решение

1. Стержни движутся с разными скоростями $v_1$ и $v_2$, площадь контура меняется, за время $\Delta t$ поток через контур изменяется на
$$\Delta\Phi = Bl(v_1 - v_2)\Delta t = Blv_\text{отн}\Delta t.$$
По закону Фарадея в контуре возникает ЭДС индукции $\mathcal{E} = \left|\dfrac{\Delta\Phi}{\Delta t}\right| = Blv_\text{отн}$ (самоиндукцией пренебрегаем).

2. Сопротивление контура $2R$, по закону Ома для замкнутой цепи
$$I = \frac{\mathcal{E}}{2R} = \frac{Blv_\text{отн}}{2R}.$$

3. На стержни с током действуют силы Ампера $F_{A1} = F_{A2} = IBl$: на первый — против его движения, на второй — по направлению движения (по правилу Ленца силы препятствуют изменению площади контура). Кроме того, на каждый стержень действует сила трения скольжения $F_\text{тр}$ — стержни одинаковые, поэтому силы трения равны (вид сверху):

4. Стержни движутся равномерно, сумма сил на каждый равна нулю:
$$F - F_{A1} - F_\text{тр} = 0, \qquad F_{A2} - F_\text{тр} = 0.$$
Отсюда $F = 2IBl = \dfrac{B^2l^2v_\text{отн}}{R}$, и
$$v_\text{отн} = \frac{FR}{B^2l^2} = \frac{0{,}1\cdot 0{,}1}{1^2\cdot 0{,}1^2} = 1~\text{м/с}.$$
