## Условие

В идеальном колебательном контуре напряжение между обкладками конденсатора меняется по закону $U_C = 20 \cdot \sin(5000t + \pi)$. Максимальное значение силы тока в контуре $I_{\max} = 0{,}2\text{ А}$. Определите индуктивность катушки. Ответ выразите в генри (Гн).

## Решение

Из закона изменения напряжения: амплитуда напряжения $U_{\max} = 20\,\text{В}$, циклическая частота $\omega = 5000\,\text{рад/с}$.

Обозначим $C$ — ёмкость конденсатора. По закону сохранения энергии в идеальном контуре $\dfrac{CU_{\max}^2}{2} = \dfrac{LI_{\max}^2}{2}$, по формуле Томсона $\omega = \dfrac{1}{\sqrt{LC}}$, т.е. $C = \dfrac{1}{\omega^2L}$.

Подставляя, получим $\dfrac{U_{\max}^2}{\omega^2L} = LI_{\max}^2$, откуда $L = \dfrac{U_{\max}}{\omega I_{\max}}$.

$L = \dfrac{20}{5000\cdot 0{,}2}\,\text{Гн} = 0{,}02\,\text{Гн}$.

Ответ: $L = 0{,}02\,\text{Гн}$.
