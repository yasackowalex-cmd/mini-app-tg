## Условие

Квадратная рамка из медного провода помещена в однородное поле электромагнита. На рисунке приведён график зависимости от времени $t$ для проекции $B_n$ вектора индукции этого поля на перпендикуляр к плоскости рамки. За время $\tau = 5$~с в рамке выделяется количество теплоты $Q = 53$~мкДж. Длина стороны рамки $l = 10$~см. Удельное сопротивление меди $\rho = 1{,}7\cdot 10^{-8}$~Ом·м. Определите площадь поперечного сечения провода $S_0$.

## Решение

1. При изменении магнитного потока через площадь рамки в ней возникает ЭДС индукции
$$\mathcal{E} = \left|\frac{\Delta\Phi}{\Delta t}\right| = \left|\frac{\Delta B_n}{\Delta t}\right|S, \qquad S = l^2.$$

2. Скорость изменения индукции определим по графику: индукция меняется линейно от $0{,}3$~Тл до $0$ за $3$~с, $\left|\dfrac{\Delta B_n}{\Delta t}\right| = \dfrac{0{,}3}{3} = 0{,}1$~Тл/с. ЭДС постоянна, постоянен и ток.

3. Сопротивление рамки (длина провода $4l$): $R = \rho\dfrac{4l}{S_0}$. По закону Джоуля — Ленца
$$Q = \frac{\mathcal{E}^2}{R}\tau = \frac{l^4\left(\frac{\Delta B_n}{\Delta t}\right)^2 S_0\tau}{4\rho l} = \frac{l^3S_0\tau}{4\rho}\left(\frac{\Delta B_n}{\Delta t}\right)^2.$$

4. Отсюда
$$S_0 = \frac{4\rho Q}{l^3\tau\left(\frac{\Delta B_n}{\Delta t}\right)^2} = \frac{4\cdot 1{,}7\cdot 10^{-8}\cdot 53\cdot 10^{-6}}{10^{-3}\cdot 5\cdot 10^{-2}} \approx 0{,}072\cdot 10^{-6}~\text{м}^2 = 0{,}072~\text{мм}^2.$$
