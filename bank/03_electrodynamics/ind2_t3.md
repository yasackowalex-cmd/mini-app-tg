## Условие

Металлический стержень, согнутый в виде буквы П, закреплён в горизонтальном положении
(см. рисунок). На параллельные стороны стержня опирается концами перпендикулярная перемычка
прямоугольного поперечного сечения массой $300$~г и длиной $1$~м. Вся система находится в однородном
вертикальном магнитном поле с индукцией $0{,}2$~Тл. Под действием постоянной горизонтальной силы
$F=1{,}6$~Н перемычка движется с постоянной скоростью $1{,}5$~м/с. Определите сопротивление
перемычки. Коэффициент трения между стержнем и перемычкой равен $0{,}2$. Сопротивлением стержня
пренебречь. Сделайте рисунок с указанием сил, действующих на перемычку.

## Решение

Обозначим $m = 0{,}3\,\text{кг}$ — масса перемычки, $l = 1\,\text{м}$ — её длина, $B = 0{,}2\,\text{Тл}$, $v = 1{,}5\,\text{м/с}$, $\mu = 0{,}2$, $R$ — искомое сопротивление перемычки, $I$ — сила индукционного тока.

На перемычку действуют: сила тяжести $m\vec g$ (вниз), сила нормальной реакции $\vec N$ (вверх), внешняя сила $\vec F$ (по направлению скорости), сила трения скольжения $\vec F_\text{тр}$ и сила Ампера $\vec F_\text{А}$ (обе против скорости — сила Ампера по правилу Ленца тормозит перемычку).

По закону электромагнитной индукции в движущейся перемычке возникает ЭДС $\mathcal{E} = Bvl$. По закону Ома для полной цепи (сопротивлением стержня пренебрегаем) $I = \dfrac{\mathcal{E}}{R} = \dfrac{Bvl}{R}$.

Сила Ампера (вектор $\vec B$ перпендикулярен перемычке): $F_\text{А} = IBl = \dfrac{B^2l^2v}{R}$.

Сила трения скольжения: $F_\text{тр} = \mu N = \mu mg$ (по вертикали $N = mg$).

Перемычка движется равномерно, поэтому по второму закону Ньютона в проекции на направление скорости $F - F_\text{тр} - F_\text{А} = 0$, т. е. $F = \mu mg + \dfrac{B^2l^2v}{R}$.

Отсюда $R = \dfrac{B^2l^2v}{F - \mu mg}$.

$R = \dfrac{0{,}2^2\cdot 1^2\cdot 1{,}5}{1{,}6 - 0{,}2\cdot 0{,}3\cdot 10}\,\text{Ом} = \dfrac{0{,}06}{1}\,\text{Ом} = 0{,}06\,\text{Ом}$.

Ответ: $R = 0{,}06\,\text{Ом}$.
