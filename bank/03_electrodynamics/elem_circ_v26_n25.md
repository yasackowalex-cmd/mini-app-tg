## Условие

Источник тока с ЭДС $\mathcal{E} = 10\text{ В}$ и внутренним сопротивлением $r$ питает цепь, состоящую из двух параллельно соединённых резисторов $R_1 = 6\text{ Ом}$ и $R_2 = 12\text{ Ом}$. Напряжение на зажимах источника равно $U = 8\text{ В}$. Определите внутреннее сопротивление $r$ источника тока. Ответ выразите в омах (Ом).

## Решение

Обозначим $R$ — сопротивление внешней цепи, $I$ — силу тока в неразветвлённой части цепи. Для параллельного соединения
$R = \dfrac{R_1R_2}{R_1 + R_2} = \dfrac{6\cdot 12}{6 + 12}\,\text{Ом} = 4\,\text{Ом}$.

Напряжение на зажимах источника равно напряжению на внешней цепи, по закону Ома для участка цепи $I = \dfrac{U}{R} = \dfrac{8}{4}\,\text{А} = 2\,\text{А}$.

По закону Ома для полной цепи $\mathcal{E} = I(R + r) = U + Ir$, откуда
$r = \dfrac{\mathcal{E} - U}{I} = \dfrac{10 - 8}{2}\,\text{Ом} = 1\,\text{Ом}$.

Ответ: $r = 1\,\text{Ом}$.
