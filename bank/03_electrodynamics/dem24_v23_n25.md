## Условие

Батарея ЭДС соединена с реостатом так, как показано на рисунке. Какова ЭДС батареи, если при силе тока в цепи $I_1 = 1$~А выделяемая на реостате мощность $N_1 = 4$~Вт, а при силе тока $I_2 = 5$~А выделяемая на реостате мощность $N_2 = 10$~Вт?

## Решение

1. Мощность на реостате $N = I^2R$, поэтому его сопротивление в первом и во втором случаях
$$R_1 = \frac{N_1}{I_1^2} = \frac{4}{1^2} = 4~\text{Ом}, \qquad R_2 = \frac{N_2}{I_2^2} = \frac{10}{5^2} = 0{,}4~\text{Ом}.$$

2. Закон Ома для полной цепи: $\mathcal{E} = I_1(R_1 + r)$ и $\mathcal{E} = I_2(R_2 + r)$.

3. Вычтем одно уравнение из другого: $I_1R_1 - I_2R_2 = (I_2 - I_1)r$, откуда
$$r = \frac{I_1R_1 - I_2R_2}{I_2 - I_1} = \frac{4 - 2}{5 - 1} = 0{,}5~\text{Ом}.$$

4. ЭДС батареи
$$\mathcal{E} = I_1(R_1 + r) = 1 \cdot (4 + 0{,}5) = 4{,}5~\text{В}.$$
