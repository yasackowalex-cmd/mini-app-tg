## Условие

Ядро лития захватывает альфа-частицу, в результате чего происходит ядерная реакция:
\[
^4_2\text{He} + \,^7_3\text{Li} \to \,^A_Z\text{X} + \,^1_0 n
\]
с образованием ядра химического элемента $^A_Z\text{X}$. Каково массовое число образовавшегося ядра $\text{X}$?

## Решение

По законам сохранения массового и зарядового чисел:

$$4 + 7 = A + 1 \;\Rightarrow\; A = 10,\qquad 2 + 3 = Z + 0 \;\Rightarrow\; Z = 5.$$

Массовое число образовавшегося ядра $A = 10$ (это ядро бора $^{10}_5\text{B}$).
