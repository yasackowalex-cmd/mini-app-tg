## Условие

Используя штатив с держателем, пружину №~2 со шкалой (или линейку), динамометр №~1 и груз №~6, соберите экспериментальную установку для измерения жёсткости пружины. Определите жёсткость пружины, подвесив к ней груз. Для измерения веса груза воспользуйтесь динамометром. Абсолютная погрешность измерения удлинения пружины составляет $\pm 2$~мм, а абсолютная погрешность измерения веса груза равна $\pm 0{,}02$~Н.

В бланке ответов:

1) сделайте рисунок экспериментальной установки, указав способы измерения удлинения пружины и силы упругости;\\
2) запишите формулу для расчёта жёсткости пружины;\\
3) укажите результаты измерения веса груза и удлинения пружины с учётом абсолютных погрешностей измерений;\\
4) запишите значение жёсткости пружины.

## Подсказка

Груз висит неподвижно: сила упругости равна весу груза. Закон Гука $F = kx$.

## Решение

Образец выполнения из сборника (комплект оборудования №~2). На реальном оборудовании числа немного другие.

1. Схема установки: пружина подвешена к штативу, удлинение $x$ измеряют линейкой как разность положений нижнего конца пружины с грузом и без груза.

```latex
\begin{tikzpicture}[scale=1, every node/.style={font=\small}]
  \fill[pattern=north east lines, pattern color=brandSecondary!60] (-0.6,0) rectangle (2.4,0.18);
  \draw[thick] (-0.6,0) -- (2.4,0);
  \draw[thick] (0,0) -- (0,-0.2);
  \draw[thick, decorate, decoration={coil, aspect=0.5, segment length=4pt, amplitude=5pt}] (0,-0.2) -- (0,-1.3);
  \draw[thick] (0,-1.3) -- (0,-1.5);
  \draw[thick] (1.6,0) -- (1.6,-0.2);
  \draw[thick, decorate, decoration={coil, aspect=0.5, segment length=6pt, amplitude=5pt}] (1.6,-0.2) -- (1.6,-2.5);
  \draw[thick] (1.6,-2.5) -- (1.6,-2.7);
  \draw[thick, fill=brandSecondary!25] (1.35,-2.7) rectangle (1.85,-3.2);
  \draw[dashed] (-0.2,-1.5) -- (1.3,-1.5);
  \draw[dashed] (0.6,-2.7) -- (1.3,-2.7);
  \draw[<->] (0.8,-1.5) -- (0.8,-2.7) node[midway, left] {$x$};
  \draw[Fvec] (1.6,-2.7) -- (1.6,-2.05) node[right] {$\vec F_\text{упр}$};
  \draw[Fvec] (1.6,-3.2) -- (1.6,-3.85) node[right] {$m\vec g$};
\end{tikzpicture}
```

2. Груз в равновесии: $F_\text{упр} = mg = P$, по закону Гука $F_\text{упр} = kx$, следовательно, $k = \dfrac{P}{x}$.

3. $x = (80 \pm 2)$~мм; $P = (0{,}80 \pm 0{,}02)$~Н.

4. $k = \dfrac{0{,}8}{0{,}08} = 10~\dfrac{\text{Н}}{\text{м}}$.

Полный балл (3) — если есть рисунок установки, формула, оба результата измерений с погрешностями и верное значение жёсткости.
