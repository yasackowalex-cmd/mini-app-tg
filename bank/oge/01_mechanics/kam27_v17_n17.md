## Условие

Используя брусок с крючком, динамометры №~1 и №~2, груз №~1, направляющую рейку, соберите экспериментальную установку для измерения коэффициента трения скольжения между бруском с грузом и поверхностью рейки. Используйте поверхность рейки, обозначенную А. Абсолютная погрешность измерения силы с помощью динамометра №~1 равна $\pm 0{,}02$~Н, а с помощью динамометра №~2 равна $\pm 0{,}1$~Н.

В бланке ответов:

1) сделайте рисунок экспериментальной установки;\\
2) запишите формулу для расчёта коэффициента трения скольжения;\\
3) укажите результаты измерения веса бруска с грузом и силы трения скольжения при движении бруска с грузом по поверхности рейки с учётом абсолютных погрешностей измерений;\\
4) запишите значение коэффициента трения скольжения.

## Подсказка

При равномерном движении сила тяги равна силе трения, а сила трения $F_\text{тр} = \mu P$.

## Решение

Образец выполнения из сборника (комплект оборудования №~2). На реальном оборудовании числа немного другие.

1. Схема: брусок с грузом равномерно тянут по рейке динамометром, расположенным горизонтально.

```latex
\begin{tikzpicture}[scale=1, every node/.style={font=\small}]
  \draw[thick] (-1.6,0) -- (1.6,0);
  \draw[thick, fill=brandSecondary!45] (-0.6,0) rectangle (0.6,0.5);
  \draw[Fvec] (0,0.5) -- (0,1.3) node[left] {$\vec N$};
  \draw[Fvec] (0,0.25) -- (0,-0.6) node[left] {$m\vec g$};
  \draw[Fvec] (-0.6,0.25) -- (-1.4,0.25) node[above] {$\vec F_\text{тр}$};
  \draw[Fvec] (0.6,0.25) -- (1.6,0.25) node[above] {$\vec F_\text{тяги}$};
  \draw[thick] (1.7,0.25) -- (2.05,0.25);\draw[thick, fill=white, rounded corners=2pt] (2.05,0.03) rectangle (3.55,0.47);\draw[thick, decorate, decoration={coil, aspect=0.5, segment length=1.3mm, amplitude=0.9mm}] (2.1,0.25) -- (2.8,0.25);\fill[brandPrimary] (2.8,0.13) rectangle (2.8499999999999996,0.37);\draw[thick] (2.8499999999999996,0.25) -- (3.5,0.25);\foreach \i in {0,...,6} \draw (2.2 + 0.18*\i,0.47) -- ++(0,-0.07);\draw[thick] (3.55,0.25) -- (3.8,0.25) arc (-90:90:0.08);
\end{tikzpicture}
```

2. При равномерном движении $F_\text{тяги} = F_\text{тр}$. Сила трения $F_\text{тр} = \mu N$, а $N = P = mg$, поэтому $F_\text{тр} = \mu P$ и
$$\mu = \frac{F_\text{тяги}}{P}.$$

3. Вес бруска с грузом измеряем динамометром №~2: $P = (1{,}5 \pm 0{,}1)$~Н. Силу тяги — динамометром №~1: $F_\text{тяги} = (0{,}30 \pm 0{,}02)$~Н.

4. $\mu = \dfrac{0{,}30}{1{,}5} = 0{,}2$.

Полный балл (3) — если есть рисунок, формула, оба результата измерений с погрешностями и верное значение коэффициента трения.
