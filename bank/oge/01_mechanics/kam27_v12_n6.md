## Условие

Шарик равномерно движется по окружности по часовой стрелке на горизонтальной поверхности стола (см. рисунок, вид сверху). Какой из изображённых векторов совпадает по направлению с равнодействующей сил, приложенных к телу в точке $A$?

## Подсказка

Куда направлено ускорение при равномерном движении по окружности? Равнодействующая направлена так же.

## Решение

При равномерном движении по окружности скорость меняется только по направлению. Ускорение — центростремительное, направлено к центру окружности $O$.

По второму закону Ньютона $\vec F = m\vec a$, поэтому равнодействующая сил тоже направлена к центру, это вектор 1.

Векторы 3 и 4 направлены по касательной (вектор 3 — по скорости), вектор 2 не направлен ни к центру, ни по касательной.
