## Условие

Используя весы, мензурку, стакан с водой, цилиндр №~2, соберите экспериментальную установку для измерения плотности материала, из которого изготовлен цилиндр №~2. Абсолютная погрешность измерения массы тела составляет $\pm 0{,}1$~г. Абсолютная погрешность измерения объёма тела равна $\pm 2$~см$^3$.

В бланке ответов:

1) сделайте рисунок экспериментальной установки для определения объёма тела;\\
2) запишите формулу для расчёта плотности;\\
3) укажите результаты измерения массы цилиндра и его объёма с учётом абсолютных погрешностей измерений;\\
4) запишите значение плотности материала цилиндра.

## Подсказка

Массу измеряют весами, объём — мензуркой по разности уровней воды до и после погружения цилиндра.

## Решение

Образец выполнения из сборника (комплект оборудования №~1). На реальном оборудовании числа немного другие.

1. Объём цилиндра измеряем мензуркой: наливаем воду, отмечаем объём $V_1$, опускаем цилиндр на нити, отмечаем $V_2$. Объём тела $V = V_2 - V_1$.

```latex
\begin{tikzpicture}[scale=1, every node/.style={font=\small}]
  \foreach \dx/\h/\lab in {0/1.1/V_1, 2.0/1.5/V_2} {
    \begin{scope}[xshift=\dx cm]
      \fill[brandLight] (0,0) rectangle (1.2,\h);
      \draw[thick] (0,2.0) -- (0,0) -- (1.2,0) -- (1.2,2.0);
      \draw[thick, brandPrimary] (0,\h) -- (1.2,\h);
      \node[left] at (0,\h) {$\lab$};
    \end{scope}
  }
  \draw[thick, fill=brandSecondary!45] (2.4,0) rectangle (2.8,0.65);
  \draw (2.6,0.65) -- (2.6,2.2);
\end{tikzpicture}
```

2. $\rho = \dfrac{m}{V}$.

3. $m = (70{,}0 \pm 0{,}1)$~г; $V = (24 \pm 2)$~мл $= (24 \pm 2)$~см$^3$.

4. $\rho = \dfrac{70{,}0}{24} \approx 2{,}9$~г/см$^3$ $= 2900$~кг/м$^3$.

Полный балл (3) — если есть все четыре элемента: рисунок установки, формула, результаты прямых измерений с погрешностями и верное значение плотности.
