## Условие

Используя штатив с муфтой, неподвижный блок, нить, два груза и динамометр, соберите экспериментальную установку для измерения работы силы упругости при равномерном подъёме грузов с использованием неподвижного блока. Определите работу, совершаемую силой упругости при подъёме грузов на высоту $10$~см. Абсолютная погрешность измерения расстояния составляет $\pm 0{,}2$~см. Абсолютная погрешность измерения силы составляет $\pm 0{,}1~\text{Н}$.

В бланке ответов:

1) сделайте рисунок экспериментальной установки;\\
2) запишите формулу для расчёта работы силы упругости;\\
3) укажите результаты прямых измерений силы упругости и пути с учётом абсолютных погрешностей измерений;\\
4) запишите значение работы силы упругости.

## Подсказка

Неподвижный блок не даёт выигрыша в силе: динамометр показывает силу натяжения нити. $A = F_\text{упр}S$.

## Решение

Образец выполнения из сборника (комплект оборудования №~6). На реальном оборудовании числа немного другие.

1. Схема: нить перекинута через неподвижный блок, к одному её концу подвешены грузы, другой конец тянут вниз динамометром. Грузы поднимают равномерно на высоту $S = 10$~см, линейкой отмечают путь, динамометр показывает силу упругости.

2. Работа силы упругости: $A = F_\text{упр}S$.

3. $F_\text{упр} = (2{,}0 \pm 0{,}1)$~Н; $S = (0{,}100 \pm 0{,}002)$~м.

4. $A = 2{,}0\cdot 0{,}1 = 0{,}2$~Дж.

Полный балл (3) — если есть рисунок, формула, оба результата измерений с погрешностями и верное значение работы.
