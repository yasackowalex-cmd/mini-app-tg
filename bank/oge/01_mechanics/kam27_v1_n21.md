## Условие

Шары массами $7$ и $3$~кг, движущиеся навстречу друг другу с одинаковыми по модулю скоростями, соударяются, после чего движутся как одно целое. В результате соударения выделилось $16{,}8$~Дж энергии. Определите, с какой по модулю скоростью относительно Земли двигались шары до соударения.

## Рисунок (TikZ)



## Подсказка

Запишите закон сохранения импульса для неупругого удара и приравняйте выделившуюся энергию убыли кинетической энергии.

## Решение

Дано: $m_1 = 7$~кг, $m_2 = 3$~кг, $Q = 16{,}8$~Дж. Найти $v$.

1. Закон сохранения импульса (ось по скорости первого шара):
$$m_1v - m_2v = (m_1 + m_2)u \;\Rightarrow\; u = \frac{v(m_1 - m_2)}{m_1 + m_2}.$$

2. Выделившаяся энергия равна убыли кинетической энергии:
$$Q = \frac{m_1v^2}{2} + \frac{m_2v^2}{2} - \frac{(m_1 + m_2)u^2}{2}.$$

3. Подставим $u$:
$$Q = \frac{v^2}{2}\left((m_1 + m_2) - \frac{(m_1 - m_2)^2}{m_1 + m_2}\right) = \frac{2m_1m_2}{m_1 + m_2}\,v^2,$$
$$v = \sqrt{\frac{Q(m_1 + m_2)}{2m_1m_2}} = \sqrt{\frac{16{,}8\cdot 10}{2\cdot 7\cdot 3}} = 2~\text{м/с}.$$
