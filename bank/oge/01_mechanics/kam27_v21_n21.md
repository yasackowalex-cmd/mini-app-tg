## Условие

Пуля массой $8$~г, движущаяся со скоростью $700~\dfrac{\text{м}}{\text{с}}$, пробила доску толщиной $8$~см. Определите скорость пули при вылете из доски, если средняя сила сопротивления, воздействующая на пулю в доске, равна $20$~кН.

## Рисунок (TikZ)



## Подсказка

Работа силы сопротивления равна изменению кинетической энергии пули: $\dfrac{mv_2^2}{2} - \dfrac{mv_1^2}{2} = -Fs$.

## Решение

Дано: $m = 8$~г $= 0{,}008$~кг, $v_1 = 700~\dfrac{\text{м}}{\text{с}}$, $s = 8$~см $= 0{,}08$~м, $F = 20$~кН $= 2\cdot 10^4$~Н. Найти $v_2$.

```latex
\begin{tikzpicture}[scale=1, every node/.style={font=\small}]
  \fill[brandSecondary!20] (0,-0.6) rectangle (1.2,0.6); \draw[thick] (0,-0.6) rectangle (1.2,0.6);
  \foreach \y in {-0.45,-0.25,...,0.5} \draw[brandSecondary!60] (0.05,\y) -- (1.15,\y+0.05);
  \draw[thick, fill=brandSecondary!80] (0.4,-0.08) -- (0.75,-0.08) arc (-90:90:0.08 and 0.08) -- (0.4,0.08) -- cycle;
  \draw[Fvec] (0.4,0) -- (-0.5,0) node[above] {$\vec F$};
  \draw[-{Stealth}, thick, brandPrimary] (0.3,0.85) -- (1.1,0.85) node[right] {$\vec v$};
  \draw[<->] (0,-0.8) -- (1.2,-0.8) node[midway, below] {$s$};
\end{tikzpicture}
```

1. Сила сопротивления направлена против движения и совершает отрицательную работу $A = -Fs$.

2. По теореме о кинетической энергии работа равна её изменению:
$$\frac{mv_2^2}{2} - \frac{mv_1^2}{2} = -Fs.$$

3. Отсюда
$$v_2 = \sqrt{v_1^2 - \frac{2Fs}{m}} = \sqrt{700^2 - \frac{2\cdot 2\cdot 10^4\cdot 0{,}08}{0{,}008}} = \sqrt{490\,000 - 400\,000} = 300~\frac{\text{м}}{\text{с}}.$$
