## Условие

Тело массой $1$~кг движется по окружности радиусом $2$~м с постоянной по модулю скоростью $3~\dfrac{\text{м}}{\text{с}}$. Чему равен модуль равнодействующей сил, приложенных к телу?

## Рисунок (TikZ)



## Подсказка

Скорость постоянна по модулю, но меняет направление: есть центростремительное ускорение $\dfrac{v^2}{R}$. Затем второй закон Ньютона.

## Решение

Дано: $m = 1$~кг, $R = 2$~м, $v = 3~\dfrac{\text{м}}{\text{с}}$. Найти $F$.

1. При равномерном движении по окружности ускорение центростремительное:
$$a = \frac{v^2}{R} = \frac{3^2}{2} = 4{,}5~\frac{\text{м}}{\text{с}^2}.$$

2. По второму закону Ньютона равнодействующая
$$F = ma = 1\cdot 4{,}5 = 4{,}5~\text{Н}.$$
