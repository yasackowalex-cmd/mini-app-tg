## Условие

Шарик массой $200$~г в течение $2$~с скатывается вниз по жёлобу, имея в начале пути скорость $0{,}5~\dfrac{\text{м}}{\text{с}}$. Равнодействующая всех сил, действующих на шарик, направлена вдоль жёлоба вниз и равна по модулю $0{,}1$~Н. Чему равна скорость шарика в конце пути?

## Подсказка

По второму закону Ньютона найдите ускорение, затем $v_2 = v_1 + at$.

## Решение

Дано: $m = 0{,}2$~кг, $t = 2$~с, $v_1 = 0{,}5$~м/с, $F = 0{,}1$~Н. Найти $v_2$.

1. Равнодействующая $\vec F$ направлена вдоль жёлоба вниз, туда же, куда скорость шарика.

```latex
\begin{tikzpicture}[scale=1, every node/.style={font=\small}]
  \draw[thick] (0,1.6) -- (4.5,0);
  \draw[thick, fill=brandSecondary!35] (1.667,1.22) circle (0.2);
  \draw[Fvec] (1.6,1.23) -- ++(-19.57:1.3) node[above right] {$\vec F$};
  \draw[thick, -{Stealth}, brandAccent] (1.55,1.6) -- ++(-19.57:0.9) node[above] {$\vec v$};
\end{tikzpicture}
```

2. По второму закону Ньютона ускорение шарика $a = \dfrac{F}{m} = \dfrac{0{,}1}{0{,}2} = 0{,}5~\text{м/с}^2$.

3. Шарик разгоняется равноускоренно:
$$v_2 = v_1 + at = 0{,}5 + 0{,}5\cdot 2 = 1{,}5~\text{м/с}.$$
