## Условие

Какую по величине работу должна совершить сила трения для полной остановки тела массой $2$~т, движущегося по горизонтальной поверхности со скоростью $36~\dfrac{\text{км}}{\text{ч}}$?

## Рисунок (TikZ)



## Подсказка

Работа силы трения равна изменению кинетической энергии: в конце тело стоит.

## Решение

Дано: $m = 2$~т $= 2000$~кг, $v_1 = 36~\dfrac{\text{км}}{\text{ч}} = 10~\dfrac{\text{м}}{\text{с}}$, $v_2 = 0$. Найти $|A_\text{тр}|$.

1. Работа силы трения равна изменению кинетической энергии тела:
$$A_\text{тр} = \frac{mv_2^2}{2} - \frac{mv_1^2}{2} = 0 - \frac{2000\cdot 10^2}{2} = -100\,000~\text{Дж}.$$

2. Знак «минус» — сила трения направлена против движения. По величине работа
$$|A_\text{тр}| = 100\,000~\text{Дж} = 100~\text{кДж}.$$
