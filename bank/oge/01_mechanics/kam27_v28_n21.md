## Условие

Из колодца глубиной $15$~м поднимают на поверхность ведро с водой массой $12$~кг в первом случае равномерно, а во втором — с ускорением $0{,}2~\dfrac{\text{м}}{\text{с}^2}$. Во сколько раз различается совершаемая при этом работа? Трением пренебречь.

## Рисунок (TikZ)



## Подсказка

Найдите силу, с которой тянут ведро, в каждом случае по второму закону Ньютона. Работа — сила, умноженная на путь.

## Решение

Дано: $m = 12$~кг, $h = 15$~м, $a = 0{,}2~\dfrac{\text{м}}{\text{с}^2}$, $g = 10~\dfrac{\text{м}}{\text{с}^2}$. Найти $\dfrac{A_2}{A_1}$.

1. Первый случай, подъём равномерный, силы уравновешены:
$$F_1 - mg = 0, \qquad A_1 = F_1h = mgh.$$

2. Второй случай, по второму закону Ньютона:
$$F_2 - mg = ma, \qquad A_2 = F_2h = (mg + ma)h.$$

3. Отношение работ:
$$\frac{A_2}{A_1} = \frac{g + a}{g} = \frac{10 + 0{,}2}{10} = 1{,}02.$$

Во втором случае работа больше в $1{,}02$ раза.
