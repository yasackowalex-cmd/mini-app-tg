## Условие

Однородный брусок массой $2$~кг подвешен на двух одинаковых вертикальных пружинах (см. рисунок).

[[рис 1]]

Какова жёсткость каждой пружины, если удлинение каждой пружины равно $4$~см? Стержень неподвижен. Масса пружинок пренебрежимо мала.

## Рисунок (TikZ)

```latex
\begin{tikzpicture}[scale=1]
  \draw[thick] (-0.4,0) -- (2.4,0); \foreach \i in {0,...,13} \draw (-0.35+0.2*\i,0) -- ++(0.12,0.12);
  \draw[thick, decorate, decoration={coil, aspect=0.5, segment length=2.4mm, amplitude=5pt}] (0,0) -- (0,-1.9);\draw[thick, decorate, decoration={coil, aspect=0.5, segment length=2.4mm, amplitude=5pt}] (2,0) -- (2,-1.9);
  \fill[brandSecondary] (-0.3,-1.9) rectangle (2.3,-2.1);
\end{tikzpicture}
```

## Подсказка

Брусок держат две пружины: $2kx = mg$.

## Решение

Дано: $m = 2$~кг, $x = 4~\text{см} = 0{,}04$~м, $g = 10~\text{м/с}^2$. Найти $k$.

1. На брусок действуют сила тяжести $m\vec g$ и две одинаковые силы упругости пружин $\vec F_\text{упр}$.

```latex
\begin{tikzpicture}[scale=1, every node/.style={font=\small}]
  \draw[thick] (-0.4,0) -- (2.4,0); \foreach \i in {0,...,13} \draw (-0.35+0.2*\i,0) -- ++(0.12,0.12);
  \draw[thick, decorate, decoration={coil, aspect=0.5, segment length=2.4mm, amplitude=5pt}] (0,0) -- (0,-1.9);\draw[thick, decorate, decoration={coil, aspect=0.5, segment length=2.4mm, amplitude=5pt}] (2,0) -- (2,-1.9);
  \fill[brandSecondary] (-0.3,-1.9) rectangle (2.3,-2.1);
  \draw[Fvec] (0.25,-1.9) -- (0.25,-1.2) node[right] {$\vec F_\text{упр}$};
  \draw[Fvec] (2.25,-1.9) -- (2.25,-1.2) node[right] {$\vec F_\text{упр}$};
  \draw[Fvec] (1,-2.0) -- (1,-3.0) node[right] {$m\vec g$};
\end{tikzpicture}
```

2. Брусок покоится, по второму закону Ньютона сумма сил равна нулю: $F_\text{упр} + F_\text{упр} = mg$, то есть $2F_\text{упр} = mg$.

3. По закону Гука $F_\text{упр} = kx$:
$$2kx = mg \;\Rightarrow\; k = \frac{mg}{2x} = \frac{2\cdot 10}{2\cdot 0{,}04} = 250~\frac{\text{Н}}{\text{м}}.$$
