## Условие

Используя весы, мензурку, стакан с водой, цилиндр №~4, соберите экспериментальную установку для измерения плотности материала, из которого изготовлен цилиндр №~4. Абсолютная погрешность измерения массы тела составляет $\pm 0{,}1$~г. Абсолютная погрешность измерения объёма тела равна $\pm 2~\text{см}^3$.

В бланке ответов:

1) сделайте рисунок экспериментальной установки для определения объёма тела;\\
2) запишите формулу для расчёта плотности;\\
3) укажите результаты измерения массы цилиндра и его объёма с учётом абсолютных погрешностей измерений;\\
4) запишите значение плотности материала цилиндра.

## Подсказка

Массу измеряют весами, объём — по подъёму уровня воды в мензурке.

## Решение

Образец выполнения из сборника (комплект оборудования №~2). На реальном оборудовании числа немного другие.

1. Схема установки для определения объёма тела: $V = V_2 - V_1$ — разность уровней воды в мензурке до и после погружения цилиндра.

```latex
\begin{tikzpicture}[scale=1, every node/.style={font=\small}]
  \fill[brandPrimary!15] (0,0) rectangle (1.2,1.3);
  \draw[thick] (0,2.0) -- (0,0) -- (1.2,0) -- (1.2,2.0);
  \draw (0,1.3) -- (1.2,1.3);
  \node[left] at (0,1.3) {$V_1$};
  \fill[brandPrimary!15] (2.2,0) rectangle (3.4,1.7);
  \draw[thick] (2.2,2.0) -- (2.2,0) -- (3.4,0) -- (3.4,2.0);
  \draw (2.2,1.7) -- (3.4,1.7);
  \draw[thick, fill=brandSecondary!60] (2.6,0) rectangle (3.0,0.8);
  \draw (2.8,0.8) -- (2.8,2.3);
  \node[right] at (3.4,1.7) {$V_2$};
\end{tikzpicture}
```

2. $\rho = \dfrac{m}{V}$.

3. $m = (95{,}0 \pm 0{,}1)$~г; $V = (34 \pm 2)$~мл $= (34 \pm 2)~\text{см}^3$.

4. $\rho = \dfrac{95{,}0}{34} \approx 2{,}79~\dfrac{\text{г}}{\text{см}^3} = 2790~\dfrac{\text{кг}}{\text{м}^3}$.

Полный балл (3) — если есть рисунок установки, формула, оба результата измерений с погрешностями и верное значение плотности.
