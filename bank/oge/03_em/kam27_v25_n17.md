## Условие

Используя источник тока, вольтметр, амперметр, ключ, реостат, соединительные провода, резистор, обозначенный $R_2$, соберите экспериментальную установку для определения мощности, выделяемой на резисторе при силе тока $0{,}5$~А. Абсолютная погрешность измерения силы тока с помощью амперметра равна $\pm 0{,}1$~А, абсолютная погрешность измерения напряжения с помощью вольтметра $\pm 0{,}2$~В.

В бланке ответов:

1) нарисуйте электрическую схему эксперимента;\\
2) запишите формулу для расчёта мощности электрического тока;\\
3) укажите результаты измерения силы тока и напряжения с учётом абсолютных погрешностей;\\
4) запишите численное значение мощности электрического тока.

## Подсказка

Мощность — произведение напряжения на резисторе и силы тока в нём.

## Решение

Образец выполнения из сборника (комплект оборудования №~3). На реальном оборудовании числа немного другие.

1. Схема: резистор $R_2$, амперметр, реостат и ключ соединены последовательно с источником, вольтметр подключён параллельно резистору. Реостатом устанавливают силу тока $0{,}5$~А.

2. Мощность тока $P = UI$.

3. $I = (0{,}5 \pm 0{,}1)$~А; $U = (4{,}2 \pm 0{,}2)$~В.

4. $P = 4{,}2\cdot 0{,}5 = 2{,}1$~Вт.

Полный балл (3) — если есть схема, формула, оба результата измерений с погрешностями и верное значение мощности.
