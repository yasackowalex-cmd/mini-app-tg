## Условие

Электровоз движется с постоянной скоростью $54~\dfrac{\text{км}}{\text{ч}}$, развивая при этой скорости силу тяги $150$~кН. Сила тока в обмотке электродвигателя равна $1000$~А. КПД двигателя электровоза равен $75\,\%$. Чему равно напряжение сети?

## Рисунок (TikZ)



## Подсказка

Полезная мощность $Fv$, затраченная $UI$, их отношение — КПД.

## Решение

Дано: $v = 54$~км/ч $= 15$~м/с, $F = 1{,}5\cdot 10^5$~Н, $I = 1000$~А, $\eta = 0{,}75$. Найти $U$.

1. Полезная мощность — мощность силы тяги: $P_\text{пол} = \dfrac{Fs}{t} = Fv$.

2. Затраченная мощность — мощность тока в двигателе: $P_\text{затр} = UI$.

3. $\eta = \dfrac{P_\text{пол}}{P_\text{затр}} = \dfrac{Fv}{UI}$, откуда
$$U = \frac{Fv}{\eta I} = \frac{150\,000\cdot 15}{0{,}75\cdot 1000} = 3000~\text{В}.$$
