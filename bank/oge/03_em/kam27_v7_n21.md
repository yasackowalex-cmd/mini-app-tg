## Условие

В электрическую сеть с напряжением $220$~В включены шесть резисторов по схеме, изображённой на рисунке. Определите мощность, потребляемую резистором $R_4$.

## Подсказка

Найдите общее сопротивление (параллельные группы из одинаковых резисторов), ток в цепи и ток через $R_4$.

## Решение

Дано: $U = 220$~В, $R_1 = R_2 = R_3 = 30$~Ом, $R_4 = R_5 = 12$~Ом, $R_6 = 4$~Ом. Найти $P_4$.

1. Три одинаковых резистора параллельно: $R_{123} = \dfrac{30}{3} = 10$~Ом. Два одинаковых параллельно: $R_{45} = \dfrac{12}{2} = 6$~Ом.

2. Участки соединены последовательно: $R = R_{123} + R_{45} + R_6 = 10 + 6 + 4 = 20$~Ом.

3. Сила тока в цепи $I = \dfrac{U}{R} = \dfrac{220}{20} = 11$~А. Через одинаковые $R_4$ и $R_5$ ток делится поровну: $I_4 = \dfrac{I}{2} = 5{,}5$~А.

4. $P_4 = I_4^2R_4 = 5{,}5^2\cdot 12 = 363$~Вт.
