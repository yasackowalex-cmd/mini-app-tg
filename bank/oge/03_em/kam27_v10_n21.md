## Условие

Три лампы мощностью $P_1 = 50$~Вт, $P_2 = 50$~Вт, $P_3 = 25$~Вт, рассчитанные на напряжение $110$~В, соединены последовательно и подключены к источнику напряжением $220$~В. Определите мощность, выделяющуюся на третьей лампе.

## Рисунок (TikZ)



## Подсказка

Найдите сопротивления ламп по номинальным мощности и напряжению. При последовательном соединении напряжения делятся пропорционально сопротивлениям.

## Решение

Дано: $P_1 = P_2 = 50$~Вт, $P_3 = 25$~Вт, $U_\text{н} = 110$~В, $U = 220$~В. Найти $P_3'$.

1. Сопротивления ламп из номинальных данных $P = \dfrac{U_\text{н}^2}{R}$:
$$R_1 = R_2 = \frac{110^2}{50} = 242~\text{Ом},\qquad R_3 = \frac{110^2}{25} = 484~\text{Ом}.$$

2. Лампы соединены последовательно, ток одинаковый, напряжения пропорциональны сопротивлениям: $U_1' = U_2'$, $U_3' = 2U_1'$. Сумма $U_1' + U_2' + U_3' = 4U_1' = 220$~В, откуда $U_1' = U_2' = 55$~В, $U_3' = 110$~В.

3. $$P_3' = \frac{U_3'^2}{R_3} = \frac{110^2}{484} = 25~\text{Вт}.$$
