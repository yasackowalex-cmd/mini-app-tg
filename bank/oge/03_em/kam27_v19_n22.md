## Условие

Определите массу никелиновой проволоки площадью поперечного сечения $1~\text{мм}^2$, из которой изготовлен реостат, если при напряжении на его концах $24$~В сила протекающего тока равна $3$~А. Плотность никелина принять равной $8800~\dfrac{\text{кг}}{\text{м}^3}$.

## Рисунок (TikZ)



## Подсказка

Найдите сопротивление по закону Ома, длину — из $R = \dfrac{\rho l}{S}$, массу — как плотность, умноженную на объём $Sl$.

## Решение

Дано: $S = 1~\text{мм}^2 = 10^{-6}~\text{м}^2$, $U = 24$~В, $I = 3$~А, $\rho = 0{,}4~\dfrac{\text{Ом}\cdot\text{мм}^2}{\text{м}}$, $\rho_\text{пл} = 8800~\dfrac{\text{кг}}{\text{м}^3}$. Найти $m$.

1. Сопротивление реостата по закону Ома:
$$R = \frac{U}{I} = \frac{24}{3} = 8~\text{Ом}.$$

2. Длина проволоки из $R = \dfrac{\rho l}{S}$:
$$l = \frac{RS}{\rho} = \frac{8\cdot 1}{0{,}4} = 20~\text{м}.$$

3. Масса проволоки:
$$m = \rho_\text{пл}Sl = 8800\cdot 10^{-6}\cdot 20 = 0{,}176~\text{кг}.$$
