## Условие

На диаграмме для двух веществ приведены значения количества теплоты, необходимого для нагревания $1$~кг вещества на $10~^\circ\text{C}$ и для плавления $100$~г вещества, нагретого до температуры плавления. Во сколько раз удельная теплота плавления $\lambda_2$ второго вещества больше удельной теплоты плавления $\lambda_1$ первого вещества?

## Подсказка

Какие столбики относятся к плавлению? При одинаковой массе удельная теплота плавления пропорциональна теплоте.

## Решение

Для теплоты плавления нужны только чёрные столбики (плавление). Массы веществ одинаковые ($100$~г), поэтому из $Q = \lambda m$ удельная теплота плавления пропорциональна $Q$.

По диаграмме $Q_1 = 6$~кДж, $Q_2 = 9$~кДж:
$$\frac{\lambda_2}{\lambda_1} = \frac{Q_2}{Q_1} = \frac{9}{6} = 1{,}5.$$
Серые столбики (нагревание) относятся к удельной теплоёмкости, здесь они не нужны.
