## Условие

На диаграмме для двух веществ приведены значения количества теплоты, необходимого для плавления $100$~г вещества, нагретого до температуры плавления. Во сколько раз удельная теплота плавления ($\lambda_2$) второго вещества больше удельной теплоты плавления первого ($\lambda_1$)?

## Подсказка

Массы веществ одинаковые. Как связаны $\lambda$ и $Q$ при одной массе?

## Решение

По диаграмме для плавления $100$~г первого вещества нужно $Q_1 = 3$~кДж, второго — $Q_2 = 9$~кДж.

Удельная теплота плавления $\lambda = \dfrac{Q}{m}$, массы одинаковые, поэтому
$$\frac{\lambda_2}{\lambda_1} = \frac{Q_2}{Q_1} = \frac{9}{3} = 3.$$
