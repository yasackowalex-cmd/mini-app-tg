## Условие

Определите КПД двигателя автомобиля, которому для выполнения работы $55{,}2$~МДж потребовалось $4$~кг бензина.

## Рисунок (TikZ)



## Подсказка

Найдите энергию сгорания $Q = qm$ и сравните с полезной работой: $\eta = \dfrac{A}{Q}$.

## Решение

Дано: $A = 55{,}2$~МДж $= 55{,}2\cdot 10^6$~Дж, $m = 4$~кг, $q = 4{,}6\cdot 10^7~\dfrac{\text{Дж}}{\text{кг}}$. Найти $\eta$.

1. При сгорании бензина выделяется
$$Q = qm = 4{,}6\cdot 10^7\cdot 4 = 18{,}4\cdot 10^7~\text{Дж} = 184~\text{МДж}.$$

2. КПД — доля этой энергии, ушедшая на полезную работу:
$$\eta = \frac{A}{Q}\cdot 100\,\% = \frac{55{,}2}{184}\cdot 100\,\% = 30\,\%.$$
