## Условие

Два одинаковых бруска массой $M = 500$~г связаны между собой невесомой нерастяжимой нитью, перекинутой через невесомый гладкий блок, неподвижно закреплённый на потолке (см. рисунок). На один из брусков кладут груз массой $m = 100$~г, и система приходит в движение. С какой силой $F$ груз будет давить на брусок? Сделайте схематический рисунок с указанием сил, действующих на бруски и груз. Обоснуйте применимость законов, используемых для решения задачи.

## Решение

\textbf{Обоснование}

1. Задачу будем решать в инерциальной системе отсчёта, связанной с Землёй.

2. Будем использовать второй закон Ньютона для материальных точек, так как бруски и груз движутся поступательно. Сопротивлением воздуха пренебрегаем. Силы, действующие на тела, постоянны, движение тел равноускоренное.

3. Так как нить нерастяжима, ускорения брусков направлены вертикально, равны по модулю и противоположны по направлению; груз лежит на правом бруске и движется вместе с ним: $|\vec a_1| = |\vec a_2| = |\vec a_3| = a$, $\vec a_1 = -\vec a_2$, $\vec a_3 = \vec a_2$ (1)

4. Так как блок и нить невесомы, трения в оси блока нет, силы натяжения нити, действующие на бруски, одинаковы по модулю: $T_1 = T_2 = T$ (2)

5. Сила $\vec N$, с которой брусок действует на груз, и сила давления $\vec F$ груза на брусок равны по модулю и противоположны по направлению согласно третьему закону Ньютона: $F = N$, $\vec F = -\vec N$ (3)

\textbf{Решение}

1. На рисунке показаны силы, действующие на бруски и груз (для наглядности груз изображён немного приподнятым над бруском). Груз с правым бруском опускается, левый брусок поднимается.

Запишем второй закон Ньютона в проекциях на направления движения тел (для левого бруска — вверх, для правого бруска и груза — вниз). С учётом (1)–(3) получим:

левый брусок: $T - Mg = Ma$;

правый брусок: $Mg + N - T = Ma$;

груз: $mg - N = ma$.

2. Складывая три уравнения, найдём модуль ускорения тел: $mg = (2M + m)a$, откуда $a = \dfrac{mg}{2M + m}$.

3. Из уравнения для груза: $N = m(g - a) = \dfrac{2Mmg}{2M + m}$.

4. С учётом (3) груз давит на брусок с силой
$F = N = \dfrac{2Mmg}{2M + m} = \dfrac{2\cdot 0{,}5\cdot 0{,}1\cdot 10}{2\cdot 0{,}5 + 0{,}1}\,\text{Н} \approx 0{,}9\,\text{Н}$.
