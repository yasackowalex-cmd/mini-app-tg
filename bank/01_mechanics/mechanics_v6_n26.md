## Условие

К концам невесомого рычага подвесили за невесомые нерастяжимые нити два сплошных груза массами $1{,}28$~кг и $0{,}32$~кг и привели рычаг в состояние равновесия. Затем рычаг с грузами расположили над водой так, что оба груза целиком оказались под водой. Первоначальное расстояние от более тяжёлого груза до точки опоры равно $20$~см. Определите, на сколько необходимо переместить точку опоры для сохранения равновесия, если объёмы обоих грузов одинаковы и равны $200\text{ см}^3$. Плотность воды примите равной $1000\text{ кг/м}^3$. Сделайте рисунок, на котором укажите силы, действующие на рычаг для двух случаев, а также на погружённые в воду грузы. Обоснуйте применимость законов, используемых для решения задачи.

## Решение

\textbf{Обоснование}

1. Задачу будем решать в инерциальной системе отсчёта, связанной с Землёй.

2. Грузы покоятся, их можно считать материальными точками: по второму закону Ньютона (при $\vec a = 0$) сумма сил, действующих на каждый груз, равна нулю.

3. Рычаг — твёрдое тело, находящееся в равновесии, поэтому сумма действующих на него сил и сумма моментов сил относительно оси (точки опоры) равны нулю; первое условие определяет силу реакции опоры, для ответа достаточно правила моментов.

4. Так как нити невесомы, сила, с которой нить действует на груз, равна по модулю силе, с которой эта нить действует на рычаг: $T_1 = T_3$, $T_2 = T_4$ — в воздухе, $T_1' = T_3'$, $T_2' = T_4'$ — в воде (1)

5. Жидкость покоится, на погружённые в неё грузы действует сила Архимеда $F_\text{А} = \rho gV$. Объёмы грузов одинаковы, поэтому силы Архимеда, действующие на них, равны по модулю: $F_{\text{А}1} = F_{\text{А}2} = F_\text{А}$ (2)

\textbf{Решение}

1. Обозначим $m_1 = 1{,}28\,\text{кг}$ и $m_2 = 0{,}32\,\text{кг}$ — массы грузов, $l_1$ и $l_2$ — первоначальные расстояния от тяжёлого и лёгкого грузов до точки опоры, $L = l_1 + l_2$ — длина рычага, $x$ — расстояние от тяжёлого груза до точки опоры после погружения.

На рычаг действуют силы натяжения нитей $\vec T_3$, $\vec T_4$ (в воде — $\vec T_3'$, $\vec T_4'$) и сила реакции опоры $\vec N$ ($\vec N'$); на каждый груз — сила тяжести, сила натяжения нити $\vec T_1$, $\vec T_2$ ($\vec T_1'$, $\vec T_2'$), а в воде — ещё и сила Архимеда $\vec F_{\text{А}1}$, $\vec F_{\text{А}2}$. 2. В воздухе из условия равновесия грузов $T_1 = m_1g$, $T_2 = m_2g$. С учётом (1) правило моментов для рычага: $T_3l_1 = T_4l_2$, т. е. $m_1gl_1 = m_2gl_2$, откуда $l_2 = \dfrac{m_1}{m_2}l_1 = 4l_1$, $L = l_1 + l_2 = 5l_1$.

3. В воде с учётом (2) на каждый груз действует сила Архимеда $F_\text{А} = \rho_\text{в} gV = 1000\cdot 10\cdot 2\cdot 10^{-4}\,\text{Н} = 2\,\text{Н}$. Из условия равновесия грузов $T_1' = m_1g - F_\text{А} = (12{,}8 - 2)\,\text{Н} = 10{,}8\,\text{Н}$, $T_2' = m_2g - F_\text{А} = (3{,}2 - 2)\,\text{Н} = 1{,}2\,\text{Н}$.

4. С учётом (1) правило моментов для рычага в новом положении: $T_3'x = T_4'(L - x)$, т. е. $T_1'x = T_2'(L - x)$, откуда $x = \dfrac{T_2'}{T_1' + T_2'}L = \dfrac{1{,}2}{12}L = 0{,}1L$.

Точку опоры нужно сместить в сторону тяжёлого груза на $\Delta l = l_1 - x$.

5. По условию $l_1 = 0{,}2\,\text{м}$, тогда $L = 5l_1 = 1\,\text{м}$, $x = 0{,}1\cdot 1\,\text{м} = 0{,}1\,\text{м}$ и $\Delta l = l_1 - x = 0{,}2\,\text{м} - 0{,}1\,\text{м} = 0{,}1\,\text{м}$.

Ответ: $\Delta l = 0{,}1\,\text{м}$ (в сторону тяжёлого груза).
