## Условие

В инерциальной системе отсчёта сила величиной $9$~Н сообщает телу массой $3$~кг ускорение $\vec a$. Какой должна быть масса тела, чтобы сила, равная $18$~Н, сообщала ему в той же системе отсчёта ускорение $4\vec a$?

## Рисунок (TikZ)



## Подсказка

По второму закону Ньютона $F = ma$. Сравните, во сколько раз изменились масса и ускорение.

## Решение

По второму закону Ньютона
$$a = \frac{F_1}{m_1} = \frac93 = 3~\text{м/с}^2.$$
Нужное ускорение $4a = 12$~м/с², тогда масса
$$m_2 = \frac{F_2}{4a} = \frac{18}{12} = 1{,}5~\text{кг}.$$
