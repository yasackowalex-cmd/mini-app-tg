## Условие

Груз массой $M = 800$~г соединён невесомой и нерастяжимой нитью, перекинутой через гладкий невесомый блок, с бруском массой $m = 400$~г. К этому бруску на лёгкой пружине жёсткостью $k = 80$~Н/м подвешен второй такой же брусок. Длина нерастянутой пружины $l = 10$~см, коэффициент трения груза о поверхность стола $\mu = 0{,}2$. Определите длину пружины при движении брусков, считая, что при этом движении она постоянна.

## Решение

\textbf{Обоснование.} Систему отсчёта, связанную с Землёй (столом), считаем инерциальной. Тела движутся поступательно, поэтому считаем их материальными точками и применяем к ним второй закон Ньютона. Нить нерастяжима, а длина пружины при движении постоянна, поэтому все три тела движутся с одинаковыми по модулю ускорениями. Нить и блок невесомы, блок гладкий, поэтому сила натяжения нити одинакова на обоих её участках. Пружина лёгкая, поэтому силы упругости на её концах одинаковы и по закону Гука равны $kx$. Груз скользит по столу, сила трения скольжения равна $\mu N$. Все силы постоянны, ускорение постоянно.

\textbf{Решение.} Обозначим $a$ — модуль ускорения тел, $T$ — силу натяжения нити, $x$ — удлинение пружины, $L$ — длину пружины при движении. Висящие бруски опускаются, груз $M$ движется к блоку.

Груз $M$: по вертикали $N = Mg$, по горизонтали по второму закону Ньютона $T - \mu Mg = Ma$.

Верхний брусок: $mg + kx - T = ma$.

Нижний брусок: $mg - kx = ma$.

Складывая три уравнения: $2mg - \mu Mg = (M + 2m)a$, откуда
$a = \dfrac{(2m - \mu M)g}{M + 2m} = \dfrac{(0{,}8 - 0{,}2\cdot 0{,}8)\cdot 10}{0{,}8 + 0{,}8}\,\text{м/с}^2 = 4\,\text{м/с}^2$.

Из уравнения для нижнего бруска: $x = \dfrac{m(g - a)}{k} = \dfrac{0{,}4\cdot(10 - 4)}{80}\,\text{м} = 0{,}03\,\text{м} = 3\,\text{см}$.

Длина пружины: $L = l + x = 10\,\text{см} + 3\,\text{см} = 13\,\text{см}$.

Ответ: $L = 13\,\text{см}$.
