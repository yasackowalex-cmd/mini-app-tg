## Условие

По неподвижной гладкой наклонной плоскости с углом $\alpha = 30^{\circ}$ движутся два одинаковых бруска массой $m = 0{,}25$~кг каждый, скреплённые между собой лёгкой пружиной с жёсткостью $k = 100$~Н/м. Верхний брусок соединён невесомой нерастяжимой нитью, перекинутой через идеальный блок, с грузом массой $M = 2$~кг (см. рисунок). Чему равна длина пружины $l$ в нерастянутом состоянии, если при движении брусков её длина постоянна и равна $L = 15$~см? Сделайте рисунок с указанием сил, действующих на тела. Обоснуйте применимость используемых законов к решению задачи.

## Решение

\textbf{Обоснование}

1. Задачу будем решать в инерциальной системе отсчёта, связанной с Землёй (с неподвижной наклонной плоскостью).

2. Будем использовать второй закон Ньютона для материальных точек, так как бруски и груз движутся поступательно. Сопротивлением воздуха пренебрегаем, плоскость гладкая — трения нет. Силы, действующие на тела, постоянны, движение тел равноускоренное.

3. Так как нить нерастяжима, а длина пружины при движении постоянна, ускорения нижнего бруска, верхнего бруска и груза $M$ равны по модулю: $|\vec a_1| = |\vec a_2| = |\vec a_3| = a$ (1)

4. Так как нить невесома, а блок идеальный (невесомый, трения в оси нет), силы натяжения нити, действующие на верхний брусок и на груз, одинаковы по модулю: $T_1 = T_2 = T$ (2)

5. Так как пружина лёгкая (невесомая), силы упругости, действующие со стороны пружины на нижний и верхний бруски, одинаковы по модулю и по закону Гука равны $kx$, где $x = L - l$ — удлинение пружины: $F_{\text{упр}1} = F_{\text{упр}2} = F_\text{упр} = kx$ (3)

\textbf{Решение}

1. Так как $Mg = 20\,\text{Н} > 2mg\sin\alpha = 2{,}5\,\text{Н}$, груз $M$ опускается, а бруски движутся вверх по плоскости. На рисунке показаны силы, действующие на бруски и груз.

Запишем второй закон Ньютона в проекциях: для брусков — на ось вдоль плоскости вверх (силы реакции $\vec N_1$ и $\vec N_2$ на эту ось не проецируются), для груза — на вертикальную ось вниз. С учётом (1)–(3) получим:

груз: $Mg - T = Ma$;

верхний брусок: $T - kx - mg\sin\alpha = ma$;

нижний брусок: $kx - mg\sin\alpha = ma$.

2. Складывая три уравнения, найдём модуль ускорения тел: $Mg - 2mg\sin\alpha = (M + 2m)a$, откуда
$a = \dfrac{(M - 2m\sin\alpha)g}{M + 2m} = \dfrac{(2 - 2\cdot 0{,}25\cdot 0{,}5)\cdot 10}{2 + 0{,}5}\,\text{м/с}^2 = 7\,\text{м/с}^2$.

3. Из уравнения для нижнего бруска найдём удлинение пружины:
$x = \dfrac{m(a + g\sin\alpha)}{k} = \dfrac{0{,}25\cdot(7 + 5)}{100}\,\text{м} = 0{,}03\,\text{м} = 3\,\text{см}$.

4. Длина нерастянутой пружины: $l = L - x = 15\,\text{см} - 3\,\text{см} = 12\,\text{см}$.

Ответ: $l = 12\,\text{см}$.
