## Условие

По неподвижной гладкой наклонной плоскости с углом $\alpha = 30^{\circ}$ движутся два одинаковых бруска массой $m = 0{,}25$~кг каждый, скреплённые между собой лёгкой пружиной с жёсткостью $k = 100$~Н/м. Верхний брусок соединён невесомой нерастяжимой нитью, перекинутой через идеальный блок, с грузом массой $M = 2$~кг (см. рисунок). Чему равна длина пружины $l$ в нерастянутом состоянии, если при движении брусков её длина постоянна и равна $L = 15$~см? Сделайте рисунок с указанием сил, действующих на тела. Обоснуйте применимость используемых законов к решению задачи.

## Решение

**Обоснование.** Систему отсчёта, связанную с Землёй (неподвижной наклонной плоскостью), считаем инерциальной. Тела движутся поступательно, поэтому считаем их материальными точками и применяем к ним второй закон Ньютона. Нить нерастяжима, а длина пружины постоянна, поэтому ускорения всех тел одинаковы по модулю. Нить невесома, блок идеальный, поэтому сила натяжения нити одинакова по обе стороны блока. Пружина лёгкая, сила упругости на её концах одинакова и по закону Гука равна $kx$. Плоскость гладкая — трения нет. Силы постоянны, ускорение постоянно.

**Решение.** Обозначим $a$ — модуль ускорения тел, $T$ — силу натяжения нити, $x = L - l$ — удлинение пружины. Так как $Mg = 20\,\text{Н} > 2mg\sin\alpha = 2{,}5\,\text{Н}$, груз $M$ опускается, а бруски движутся вверх по плоскости.

По второму закону Ньютона (для брусков — в проекции на ось вдоль плоскости вверх, нормальная реакция на эту ось не проецируется):
груз: $Mg - T = Ma$;
верхний брусок: $T - kx - mg\sin\alpha = ma$;
нижний брусок: $kx - mg\sin\alpha = ma$.

Складывая уравнения: $Mg - 2mg\sin\alpha = (M + 2m)a$, откуда
$a = \dfrac{(M - 2m\sin\alpha)g}{M + 2m} = \dfrac{(2 - 2\cdot 0{,}25\cdot 0{,}5)\cdot 10}{2 + 0{,}5}\,\text{м/с}^2 = 7\,\text{м/с}^2$.

Из уравнения для нижнего бруска: $x = \dfrac{m(a + g\sin\alpha)}{k} = \dfrac{0{,}25\cdot(7 + 5)}{100}\,\text{м} = 0{,}03\,\text{м} = 3\,\text{см}$.

Длина нерастянутой пружины: $l = L - x = 15\,\text{см} - 3\,\text{см} = 12\,\text{см}$.

Ответ: $l = 12\,\text{см}$.
