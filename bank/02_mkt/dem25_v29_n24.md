## Условие

В закрытом сосуде при температуре $100$~°С находится влажный воздух с относительной влажностью $70\,\%$ под давлением $100$~кПа. Объём сосуда изотермически уменьшили в $3$ раза. До какой абсолютной температуры надо вместо этого нагреть воздух без изменения объёма сосуда, чтобы получить такое же конечное давление? Объёмом сконденсировавшейся воды пренебречь.

## Решение

1. Определим, при каком изотермическом сжатии пар станет насыщенным. При $100$~°С давление насыщенного водяного пара равно нормальному атмосферному давлению: $p_\text{н} = 10^5$~Па. По закону Бойля — Мариотта $p_{\text{п}1}V_1 = p_\text{н}V_\text{н}$. Начальная относительная влажность $\varphi = \dfrac{p_{\text{п}1}}{p_\text{н}} = 0{,}7$, поэтому $\dfrac{V_1}{V_\text{н}} = \dfrac{p_\text{н}}{p_{\text{п}1}} = \dfrac{1}{0{,}7} = \dfrac{10}{7} < 3$. Следовательно, при изотермическом уменьшении объёма в $3$ раза пар станет насыщенным, часть его сконденсируется, давление пара будет равно $p_\text{н}$.

2. Начальное и конечное парциальные давления сухого воздуха (законы Дальтона и Бойля — Мариотта):
$$p_{\text{в}1} = p_1 - \varphi p_\text{н} = 10^5 - 0{,}7\cdot 10^5 = 0{,}3\cdot 10^5~\text{Па},\qquad p_{\text{в}2} = p_{\text{в}1}\frac{V_1}{V_2} = 3\cdot 0{,}3\cdot 10^5 = 0{,}9\cdot 10^5~\text{Па}.$$

3. Конечное давление влажного воздуха по закону Дальтона:
$$p_2 = p_{\text{в}2} + p_\text{н} = 0{,}9\cdot 10^5 + 10^5 = 1{,}9\cdot 10^5~\text{Па}.$$

4. При нагревании влажного воздуха без изменения объёма водяной пар остаётся ненасыщенным, влажный воздух можно считать идеальным газом с постоянным количеством вещества. По закону Шарля $\dfrac{p_1}{T_1} = \dfrac{p_2}{T_2}$, откуда
$$T_2 = T_1\frac{p_2}{p_1} = 373\cdot\frac{1{,}9\cdot 10^5}{10^5} \approx 709~\text{К}.$$
