## Условие

Неон массой $20$~г изобарно нагрели, сообщив ему количество теплоты, равное $10$~кДж. Какую работу совершил газ в этом процессе?

## Решение

1. Неон — одноатомный газ, его внутренняя энергия $U = \dfrac{3}{2}\nu RT$. В изобарном процессе работа газа $A = p\Delta V = \nu R\Delta T$ (из уравнения Менделеева — Клапейрона $pV = \nu RT$ при $p = \text{const}$).

2. Изменение внутренней энергии $\Delta U = \dfrac{3}{2}\nu R\Delta T = \dfrac{3}{2}A$.

3. По первому закону термодинамики $Q = \Delta U + A = \dfrac{3}{2}A + A = \dfrac{5}{2}A$, откуда
$$A = \frac{2Q}{5} = \frac{2\cdot 10}{5} = 4~\text{кДж}.$$

Масса газа для ответа не понадобилась.
