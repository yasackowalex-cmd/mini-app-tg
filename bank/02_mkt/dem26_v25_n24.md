## Условие

В вертикальном цилиндре с гладкими стенками, открытом сверху, под поршнем массой $M$ и конечной площадью основания находится одноатомный идеальный газ. В первоначальном состоянии поршень покоится на высоте $h$, опираясь на выступы на внутренней стороне стенок цилиндра (см. рисунок а). Давление газа $p_0$ равно внешнему атмосферному. Газу сообщили количество теплоты $Q$, и в результате медленного расширения газа нижняя сторона поршня оказалась на высоте $H$ (см. рисунок б). Чему равна площадь основания поршня $S$? Тепловыми потерями пренебречь.

## Решение

1. Систему отсчёта, связанную с Землёй, считаем инерциальной. Поршень поднимается медленно, его ускорение пренебрежимо мало, сумма сил, действующих на него, равна нулю:

```latex
\begin{tikzpicture}[scale=1.1, every node/.style={font=\small}]
\draw[thick, fill=gray!35] (0,0) rectangle (1.6,0.35);
  \node at (0.8,0.175) {$M$};
  \draw[-{Stealth[scale=0.9]}, very thick, brandPrimary] (0.8,0.35) -- (0.8,1.3) node[right] {$p_1S$};
  \draw[-{Stealth[scale=0.9]}, very thick, brandPrimary] (0.4,1.2) -- (0.4,0.35);
  \node[left] at (0.4,1.0) {$p_0S$};
  \draw[-{Stealth[scale=0.9]}, very thick, brandPrimary] (1.2,0) -- (1.2,-0.9) node[right] {$M\vec g$};
\end{tikzpicture}
```

$$p_1S - p_0S - Mg = 0, \qquad p_1 = p_0 + \frac{Mg}{S},$$
где $p_1$ — давление газа при движении поршня.

2. Пока давление газа меньше $p_1$, поршень лежит на выступах и газ нагревается при постоянном объёме. Затем поршень поднимается при постоянном давлении $p_1$.

3. Внутренняя энергия одноатомного идеального газа $U = \dfrac32\nu RT = \dfrac32 pV$. В начальном состоянии $U_0 = \dfrac32 p_0Sh$, в конечном $U = \dfrac32 p_1SH = \dfrac32(p_0S + Mg)H$.

4. Работа газа совершается только при подъёме поршня: $A = p_1S(H - h) = (p_0S + Mg)(H - h)$. По первому началу термодинамики
$$Q = U - U_0 + A = \frac32(p_0S + Mg)H - \frac32 p_0Sh + (p_0S + Mg)(H - h),$$
что после преобразований даёт
$$Q = \frac32 Mgh + \frac52(p_0S + Mg)(H - h).$$

5. Отсюда
$$S = \frac{2Q - 3Mgh - 5Mg(H - h)}{5p_0(H - h)}.$$

Ответ: $S = \dfrac{2Q - 3Mgh - 5Mg(H - h)}{5p_0(H - h)}$.
