## Условие

Какое количество теплоты необходимо для того, чтобы расплавить $20$~г свинца, взятого при температуре плавления?

## Рисунок (TikZ)


## Решение

Свинец уже при температуре плавления, теплота идёт только на плавление: $Q = \lambda m$, где удельная теплота плавления свинца $\lambda = 0{,}25\cdot 10^5$~Дж/кг:
$$Q = 0{,}25\cdot 10^5\cdot 0{,}02 = 500~\text{Дж}.$$

Ответ: 500.
