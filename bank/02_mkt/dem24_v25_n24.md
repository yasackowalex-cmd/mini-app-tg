## Условие

Два теплоизолированных сосуда, объёмы которых $V_1 = 2V$ и $V_2 = V$, соединены между собой трубкой с вентилем. Вентиль закрыт. Сосуды содержат разреженный аргон и разреженный криптон в количествах $\nu_1$ и $\nu_2 = 2\nu_1$ при температурах $T_1$ и $T_2 = 2T_1$ соответственно. Каким будет давление в сосудах, если вентиль открыть? Объёмом трубки пренебречь.

## Решение

1. Сосуды теплоизолированы, а при открытии вентиля газы не совершают работы над внешними телами. По первому началу термодинамики суммарная внутренняя энергия одноатомных газов сохраняется:
$$\frac32\nu_1RT_1 + \frac32\nu_2RT_2 = \frac32(\nu_1 + \nu_2)RT,$$
где $T$ — установившаяся температура. Подставим $\nu_2 = 2\nu_1$, $T_2 = 2T_1$: $\nu_1T_1 + 4\nu_1T_1 = 3\nu_1T$, откуда $T = \dfrac53T_1$.

2. Газы заполняют весь объём $3V$. По уравнению Менделеева — Клапейрона парциальные давления
$$p_1 = \frac{\nu_1RT}{3V}, \qquad p_2 = \frac{\nu_2RT}{3V}.$$

3. По закону Дальтона давление смеси
$$p = p_1 + p_2 = \frac{3\nu_1RT}{3V} = \frac{\nu_1RT}{V} = \frac53 \cdot \frac{\nu_1RT_1}{V}.$$
