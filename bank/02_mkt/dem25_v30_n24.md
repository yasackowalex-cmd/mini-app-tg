## Условие

В закрытом сосуде при температуре $100$~°С находится влажный воздух с относительной влажностью $60\,\%$ под давлением $100$~кПа. Объём сосуда изотермически уменьшили в $2{,}5$ раза. Во сколько раз надо вместо этого увеличить абсолютную температуру без изменения объёма сосуда, чтобы получить такое же конечное давление? Объёмом сконденсировавшейся воды пренебречь.

## Решение

1. Определим, при каком изотермическом сжатии пар станет насыщенным. При $100$~°С давление насыщенного водяного пара равно нормальному атмосферному давлению: $p_\text{н} = 10^5$~Па. По закону Бойля — Мариотта $p_{\text{п}1}V_1 = p_\text{н}V_\text{н}$. Начальная относительная влажность $\varphi = \dfrac{p_{\text{п}1}}{p_\text{н}} = 0{,}6$, поэтому $\dfrac{V_1}{V_\text{н}} = \dfrac{p_\text{н}}{p_{\text{п}1}} = \dfrac{1}{0{,}6} = \dfrac53 < 2{,}5$. Следовательно, при изотермическом уменьшении объёма в $2{,}5$ раза пар станет насыщенным, часть его сконденсируется, давление пара будет равно $p_\text{н}$.

2. Начальное и конечное парциальные давления сухого воздуха (законы Дальтона и Бойля — Мариотта):
$$p_{\text{в}1} = p_1 - \varphi p_\text{н} = 10^5 - 0{,}6\cdot 10^5 = 0{,}4\cdot 10^5~\text{Па},\qquad p_{\text{в}2} = p_{\text{в}1}\frac{V_1}{V_2} = 2{,}5\cdot 0{,}4\cdot 10^5 = 1\cdot 10^5~\text{Па}.$$

3. Конечное давление влажного воздуха по закону Дальтона:
$$p_2 = p_{\text{в}2} + p_\text{н} = 1\cdot 10^5 + 10^5 = 2\cdot 10^5~\text{Па}.$$

4. При нагревании влажного воздуха без изменения объёма водяной пар остаётся ненасыщенным, влажный воздух можно считать идеальным газом с постоянным количеством вещества. По закону Шарля $\dfrac{p_1}{T_1} = \dfrac{p_2}{T_2}$, откуда
$$\frac{T_2}{T_1} = \frac{p_2}{p_1} = \frac{2\cdot 10^5}{10^5} = 2.$$
