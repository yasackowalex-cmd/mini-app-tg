## Условие

Два теплоизолированных сосуда, объёмы которых $V_1 = 1{,}5V$ и $V_2 = V$, соединены между собой трубкой с вентилем. Вентиль закрыт. Сосуды содержат разреженный гелий и разреженный аргон в количествах $\nu_1$ и $\nu_2 = 3\nu_1$ при температурах $T_1$ и $T_2 = 3T_1$ соответственно. Каким будет давление в сосудах, если вентиль открыть? Объёмом трубки пренебречь.

## Решение

1. Сосуды теплоизолированы, а при открытии вентиля газы не совершают работы над внешними телами. По первому началу термодинамики суммарная внутренняя энергия одноатомных газов сохраняется:
$$\frac32\nu_1RT_1 + \frac32\nu_2RT_2 = \frac32(\nu_1 + \nu_2)RT,$$
где $T$ — установившаяся температура. Подставим $\nu_2 = 3\nu_1$, $T_2 = 3T_1$: $\nu_1T_1 + 9\nu_1T_1 = 4\nu_1T$, откуда $T = 2{,}5T_1$.

2. Газы заполняют весь объём $V_1 + V_2 = 2{,}5V$. По уравнению Менделеева — Клапейрона парциальные давления
$$p_1 = \frac{\nu_1RT}{2{,}5V}, \qquad p_2 = \frac{\nu_2RT}{2{,}5V}.$$

3. По закону Дальтона давление смеси
$$p = p_1 + p_2 = \frac{4\nu_1RT}{2{,}5V} = \frac{4\nu_1R \cdot 2{,}5T_1}{2{,}5V} = \frac{4\nu_1RT_1}{V}.$$
