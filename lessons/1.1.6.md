## Конспект

\subsection{Математика для кинематики}
Проекции: $a_x=a\cos\alpha$, $a_y=a\sin\alpha$ ($\alpha$ — угол к оси $Ox$). Знак: $+$ по оси, $-$ против.
Для вектора с началом $(x_1;y_1)$ и концом $(x_2;y_2)$ проекция на $Ox$ равна $x_2-x_1$.
Модуль: $|\vec a|=\sqrt{a_x^{2}+a_y^{2}}$. Сложение по проекциям: $\vec c=\vec a+\vec b\Rightarrow c_x=a_x+b_x$.

Перевод: $1$ км/ч $=\dfrac{1}{3{,}6}$ м/с; $\ 36$ км/ч $=10$ м/с; $\ 72$ км/ч $=20$ м/с.

\subsection{Равномерное прямолинейное движение}
Признак: $\vec v=\text{const}$, ускорение нулевое.
\[
v_x=\dfrac{x-x_0}{t},\qquad x(t)=x_0+v_x t,\qquad S=vt.
\]
$x(t)$ — прямая, наклон $=v_x$. $v_x(t)$ — горизонталь; площадь под ней $=$ перемещение.

\subsection{Равноускоренное движение}
Признак: $\vec a=\text{const}$. Разгон: $\vec a\uparrow\uparrow\vec v$; торможение: $\vec a\uparrow\downarrow\vec v$.
\[
a_x=\dfrac{v_x-v_{0x}}{t},\quad v_x=v_{0x}+a_x t,\quad
x=x_0+v_{0x}t+\dfrac{a_x t^{2}}{2},\quad s_x=\dfrac{v_x^{2}-v_{0x}^{2}}{2a_x}.
\]
$v_x(t)$ — прямая, наклон $=a_x$; путь $=$ площадь. $x(t)$ — парабола.

\subsection{Свободное падение}
$\vec a=\vec g$, $g=10$~м/с$^2$ (\emph{даётся}). Из покоя: $v=gt$, $\ h=\dfrac{gt^{2}}{2}$, $\ v=\sqrt{2gh}$.
Вверх с $v_0$: $h_{\max}=\dfrac{v_0^{2}}{2g}$, время подъёма $t_\uparrow=\dfrac{v_0}{g}$.

\subsection{Движение под углом к горизонту}
Раскладываем по осям: $v_{0x}=v_0\cos\alpha$, $v_{0y}=v_0\sin\alpha$. По $Ox$ — равномерное, по $Oy$ — с $g$.
\[
H=\dfrac{v_0^{2}\sin^{2}\alpha}{2g},\qquad t_{\text{пол}}=\dfrac{2v_0\sin\alpha}{g},\qquad l=\dfrac{v_0^{2}\sin 2\alpha}{g}.
\]
Время подъёма вдвое меньше полного: $t_\uparrow=\dfrac{v_0\sin\alpha}{g}$.
Горизонтальный бросок с высоты $H$: $\ t=\sqrt{2H/g}$, $\ l=v_0 t$.

\subsection{Движение по окружности}
Скорость — по касательной, $a_{\text{ц}}$ — к центру.
\[
T=\dfrac{t}{N},\quad \nu=\dfrac{N}{t}=\dfrac1T,\quad \omega=\dfrac{2\pi}{T}=2\pi\nu,\quad
v=\dfrac{2\pi R}{T}=\omega R,\quad a_{\text{ц}}=\dfrac{v^{2}}{R}=\omega^{2}R.
\]
Неравномерное движение: тангенциальное $a_\tau=\dfrac{\Delta v}{\Delta t}$; полное $a=\sqrt{a_{\text{ц}}^{2}+a_\tau^{2}}$.

\subsection{Как читать график $x(t)$}
Значение $=$ координата тела. Наклон касательной $=v_x$: график растёт — движение по оси, убывает — против, горизонталь — покой. Парабола — равноускоренное движение.

[[рис 1]]

\subsection{Как читать график $v_x(t)$}
Значение $=$ проекция скорости ($v_x>0$ — по оси, $v_x<0$ — против). Наклон $=a_x$.
\textbf{Площадь под графиком $=$ перемещение}; участок ниже оси входит со знаком минус.

[[рис 2]]

 Перемещение $=$ (площадь над осью) $-$ (площадь под осью). Путь $=$ сумма модулей площадей.

\subsection{Перемещение и путь}
Перемещение $s_x=x_{\text{кон}}-x_{\text{нач}}$ — со знаком, может быть отрицательным. Путь $S$ — сумма модулей
участков, всегда $\ge 0$. Совпадают по модулю только при движении в одну сторону.
Средняя скорость $v_\text{ср}=\dfrac{S}{t}$ — весь путь на всё время.

\subsection{Ловушки}
1. Знак $a_x$ — это направление вдоль оси, а не «разгон/торможение». Разгон — когда $\vec a\uparrow\uparrow\vec v$.\\
2. График $v_x(t)$ не даёт координату — только перемещение $s_x$ (через площадь).\\
3. Пересечение графиков $v_x(t)$ — равенство скоростей, а не встреча (встреча — равенство $x$).\\
4. $g$ подставляем только при свободном падении; в задачах на окружность — нет.\\
5. У всех точек тела на одной оси период $T$ одинаков; $v$ и $a_{\text{ц}}$ растут с радиусом.\\
6. При равномерном движении по окружности $\vec v\perp\vec{a_{\text{ц}}}$.\\
7. Из покоя равноускоренно: пути за равные времена $1:3:5:7$; координаты $1:4:9:16$.\\
8. Средняя скорость — не среднее арифметическое скоростей: сначала путь и время, потом деление.
