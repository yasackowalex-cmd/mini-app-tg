## Условие

Постройте векторы $\vec a+\vec b$ и $\vec a-\vec b$ по правилу треугольника.

[[рис 1]]

## Рисунок (TikZ)

```latex
\begin{tikzpicture}[>=Stealth,scale=1.0]
  \draw[brandSecondary!25, thin] (-1,-1) grid (5,3);
  \draw[->,thick,brandPrimary] (0,0) -- (3,1) node[midway,below right] {$\vec a$};
  \draw[->,thick,brandSecondary] (3,0) -- (4,2) node[midway,right] {$\vec b$};
\end{tikzpicture}
```

## Решение


```latex
\begin{tikzpicture}[>=Stealth,scale=1.0]
  \draw[brandSecondary!25, thin] (-1, -1) grid (5,4);
  \draw[->,thick,brandPrimary] (0,0) -- (3,1) node[midway,below] {$\vec a$};
  \draw[->,thick,brandSecondary] (3,1) -- (4,3) node[midway,right] {$\vec b$};
  \draw[->,very thick,brandAccent] (0,0) -- (4,3) node[midway,above left] {$\vec a+\vec b$};
  \node at (2,-0.6) {\small сумма};
  \begin{scope}[xshift=6cm]
    \draw[brandSecondary!25, thin] (-1,-1) grid (4,4);
    \draw[->,thick,brandPrimary] (0,1) -- (3,2) node[midway,above] {$\vec a$};
    \draw[->,thick,brandSecondary] (3,2) -- (2,0) node[midway,right] {$-\vec b$};
    \draw[->,very thick,brandAccent] (0,1) -- (2,0) node[midway,below left] {$\vec a-\vec b$};
    \node at (2,-0.6) {\small разность};
  \end{scope}
\end{tikzpicture}
```
